# Palash Joshi — Portfolio

A responsive personal portfolio website built for the Web Technology portfolio project.

## Technologies
- HTML5 (semantic sections, navigation and contact form)
- CSS3 (element, class and ID selectors, hover effects, responsive media queries)
- Vanilla JavaScript (mobile navigation, dark/light theme, scroll reveal and contact form validation)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. No package installation or build step is required.

## Project structure
```text
palash-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features
- Home / About, Skills, Projects and Contact sections
- Responsive layout for laptop and mobile screens
- Dark/light theme toggle
- Mobile navigation menu
- Animated section reveals
- Required-field and email validation on the contact form
- Contact form prepares an email using the visitor's default email application
